# 人格设定编辑器

自带的人格编辑页里，对话示例只能往末尾加。五十对的时候，想在中间补一对、想把某一对挪到前面，都做不到。

这个插件把示例拆成一个一个「对」，一对一张卡片。

## 用法

1. 装好后，在插件卡片上点「查看界面」。
2. 左上角下拉选人格，列表里会显示每个人格有几对。
3. 每一对有这些按钮：

   | 按钮 | 作用 |
   |---|---|
   | 拖动把手 | 按住把手拖动调整顺序 |
   | 上方插入 / 下方插入 | 在这一对的前面或后面插一张空对 |
   | 复制 | 把这一对原样复制一份放到下面 |
   | 删除 | 删掉这一对（会问一次） |

4. 顶部的「新对」在最后加一对。
5. 系统提示词也能就地改，标题旁会显示字数。
6. 工具和技能可分别选全部可用、一个都不用或自选；自选时可添加、删除名称。
7. 改完点「保存」，整份写回。

有没保存的改动时，顶上的状态会变黄；这时候切换人格或关页面，会先问你。

## 导出

点「导出」，把当前这个人格整份存成一个文件：系统提示词、对话示例、工具、技能、
自定义报错回复，一个都不少。页面上还没保存的改动也会一起进去，所以改到一半想先留个底，
直接点导出就行。

点「导出全部」，把所有人格打成一个包，文件名带上日期。换机器、换手机的时候，
先导出全部，到那边导入，人格不用一个一个重敲。

要注意：「导出」取的是页面上此刻的内容，没保存的改动也在里面；
「导出全部」取的是已经保存的内容，没保存的改动不在里面。所以导出全部之前，先把手上那份存了。

文件是能直接看懂的文本，改坏了也能手动改回来。

## 导入

点「导入」，选一个文件。文件里可以是一个人，也可以是一整包。

导入前会先把每一项列出来：

| 位置 | 作用 |
|---|---|
| 左边输入框 | 人格标识，可以改；改完重名状态会跟着变 |
| 中间说明 | 这一项有几对、多少字，名字是否已经存在 |
| 右边下拉 | 新建 / 覆盖 / 跳过 |

底下三个按钮可以一次全设成新建、覆盖或跳过。确认按钮上会写清楚
「新建几个、覆盖几个、跳过几个」，看到什么就是什么。

### 关于导入后缀

助手自带的导入在重名时会给人格加尾巴：先加 `_imported`，还重就加 `_imported_1`。
这个插件默认把这种尾巴认出来并去掉，导入框里直接就是干净的名字。
不想要这个行为，把上面的勾去掉即可；已经手动改过的行不会被自动改回去。

### 覆盖会覆盖掉什么

覆盖用的是同一个人格标识，提示词、示例、工具、技能、报错话术都会被文件里的内容换掉，
所属文件夹和排序保持原样。拿不准就把那一行改成「跳过」，先新建一个看看。

## 保存方式

整份写回，不做增量。原因是增量保存一旦中途失败，会留下半新半旧的数据，比整份失败更难收拾。

保存前会扫一遍：每一对的用户和助手都不能是空的。有空的话会告诉你是第几对，你确认了也能强行存。

## 兼容

- 数据库里对话示例可能是列表，也可能是一段 JSON 字符串，两种都能读；写入统一成列表。
- 对话示例数量为奇数或数据格式错误时，页面会显示错误，避免保存时丢失数据。
- 工具和技能的自选列表为空时，保存结果与「一个都不用」相同。
- 导入时会认助手原生的导出文件（只有提示词和示例那种）和本插件的整份文件；
  更早的备份里用「提示词、名字」两个老字段的，也认得。
- 导入时如果文件里带了某个文件夹，而这台机器上没有这个人格文件夹，会放到根目录，不会报错。
- 只调人格管理器的公开方法：读列表、读单个、更新、新建、读文件夹。不直接写数据库，不改本体文件。

## 已知限制

- 保存前不做「别人也改过」的冲突检测。单人使用没问题；两个人同时改同一个人格，后保存的会覆盖先保存的。
- 一次把所有示例整段发给页面，五十对左右没问题，上千对会慢。
- 导入是一个人一个人写进去的，中途某一项失败，前面已经写进去的不会退回来；失败的项会在提示里列出来。
